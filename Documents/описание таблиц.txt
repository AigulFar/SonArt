В проекте используются реальные агрегированные данные из официальных отчётов учреждений культуры и синтетические данные, созданные для демонстрации работы аналитики и ML-моделей.
---
## 1. `institutions_official`

**Назначение:** реальные данные об учреждениях культуры и их официальных показателях.

**Одна строка = одно учреждение.**

| Столбец                    | Описание                                                | Возможные значения                                                                                                                        |
| -------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `institution_id`           | Уникальный ID учреждения                                | Числовой ID                                                                                                                               |
| `institution`              | Название учреждения                                     | Название учреждения                                                                                                                       |
| `center`                   | Федеральный округ / региональный центр                  | Текст                                                                                                                                     |
| `institution_type`         | Тип учреждения                                          | `Изобразительное искусство / культура`, `Театр / хореографическое`, `Культурное / образовательное`, `Цирковое / эстрадное`, `Музыкальное` |
| `report_year`              | Год отчёта                                              | `2026`                                                                                                                                    |
| `events_2025`              | Количество мероприятий в 2025 году                      | `0` и выше                                                                                                                                |
| `events_2026`              | Количество мероприятий в 2026 году                      | `1` и выше                                                                                                                                |
| `event_growth_pct`         | Изменение количества мероприятий относительно 2025 года | Процент, может быть отрицательным                                                                                                         |
| `trained_people_total`     | Количество обученных людей                              | Число                                                                                                                                     |
| `resident_creators`        | Количество резидентов / участников творческих программ  | Число                                                                                                                                     |
| `creative_products_total`  | Количество созданных творческих продуктов               | Число                                                                                                                                     |
| `patents_copyrights_total` | Количество патентов и объектов авторского права         | Число                                                                                                                                     |
| `publications`             | Количество публикаций                                   | Число                                                                                                                                     |
| `service_revenue_total`    | Доход от оказания услуг                                 | Число в рублях                                                                                                                            |
| `data_quality`             | Информация о качестве исходных данных                   | `OK` или описание найденного расхождения                                                                                                  |
| `data_source`              | Источник данных                                         | `official`                                                                                                                                |

## 2. `events_synthetic`

**Назначение:** синтетические данные о мероприятиях.

| Столбец          | Описание                                    | Возможные значения                                                           |
| ---------------- | ------------------------------------------- | ---------------------------------------------------------------------------- |
| `event_id`       | Уникальный ID мероприятия                   | Уникальный ID                                                                |
| `institution_id` | ID учреждения, которое проводит мероприятие | Значение из `institutions_official.institution_id`                           |
| `event_name`     | Название мероприятия                        | Текст                                                                        |
| `event_type`     | Тип мероприятия                             | `Выставка`, `Лекция`, `Мастер-класс`, `Творческая встреча`, `Концерт`        |
| `date`           | Дата проведения                             | Дата                                                                         |
| `day_of_week`    | День недели                                 | `Monday`, `Tuesday`, `Wednesday`, `Thursday`, `Friday`, `Saturday`, `Sunday` |
| `start_time`     | Время начала                                | Например `11:00`, `15:00`, `18:00`, `20:00`                                  |
| `duration_min`   | Продолжительность в минутах                 | `60`, `90`, `120`, `180`                                                     |
| `capacity`       | Вместимость площадки                        | Число                                                                        |
| `price_rub`      | Стоимость билета                            | `0`, `100`, `150`, `200`, `300`, `400`, `500`, `800`                         |
| `target_age_min` | Минимальный возраст целевой аудитории       | `10`, `14`, `16`                                                             |
| `target_age_max` | Максимальный возраст целевой аудитории      | `55`, `60`, `65`, `70`                                                       |
| `data_source`    | Источник данных                             | `synthetic`                                                                  |

## 3. `attendance_synthetic`

**Назначение:** информация о посещаемости мероприятий.

| Столбец            | Описание                                                       | Возможные значения                      |
| ------------------ | -------------------------------------------------------------- | --------------------------------------- |
| `event_id`         | ID мероприятия                                                 | Значение из `events_synthetic.event_id` |
| `registered`       | Количество зарегистрированных посетителей                      | Число                                   |
| `visitors`         | Фактическое количество посетителей                             | Число                                   |
| `repeat_visitors`  | Количество посетителей, которые уже посещали учреждение раньше | Число                                   |
| `new_visitors`     | Количество новых посетителей                                   | Число                                   |
| `fill_rate_pct`    | Заполняемость площадки                                         | `0–100%`                                |
| `no_show_rate_pct` | Доля зарегистрированных посетителей, которые не пришли         | Процент                                 |
| `data_source`      | Источник данных                                                | `synthetic`                             |

### Основные расчётные показатели

**Новые посетители:**

`new_visitors = visitors - repeat_visitors`

**Заполняемость:**

`fill_rate_pct = visitors / capacity × 100`

## 4. `audience_synthetic`

**Назначение:** синтетические профили посетителей.

| Столбец               | Описание                         | Возможные значения                                                  |
| --------------------- | -------------------------------- | ------------------------------------------------------------------- |
| `visitor_id`          | Уникальный ID посетителя         | Уникальный ID                                                       |
| `age`                 | Возраст посетителя               | `10–80` лет                                                         |
| `age_group`           | Возрастная группа                | `school`, `young`, `adult`, `mature`, `senior`                      |
| `favorite_event_type` | Предпочитаемый тип мероприятия   | `Мастер-класс`, `Концерт`, `Лекция`, `Спектакль`, `Выставка`, `Шоу` |
| `visit_count_2026`    | Количество посещений за 2026 год | `1–20`                                                              |
| `feedback_count_2026` | Количество оставленных отзывов   | `0–10`                                                              |
| `avg_rating`          | Средняя оценка мероприятий       | `2.6–5.0`                                                           |
| `engagement_score`    | Уровень вовлечённости посетителя | `0–100`                                                             |
| `data_source`         | Источник данных                  | `synthetic`                                                         |

---

## 5. `feedback_synthetic`

**Назначение:** синтетические отзывы посетителей.

| Столбец       | Описание                                 | Возможные значения                      |
| ------------- | ---------------------------------------- | --------------------------------------- |
| `feedback_id` | Уникальный ID отзыва                     | Уникальный ID                           |
| `event_id`    | ID мероприятия, о котором оставлен отзыв | Значение из `events_synthetic.event_id` |
| `rating`      | Оценка мероприятия                       | `1`, `2`, `3`, `4`, `5`                 |
| `text`        | Текст отзыва                             | Текст                                   |
| `sentiment`   | Тональность отзыва                       | `positive`, `neutral`, `negative`       |
| `data_source` | Источник данных                          | `synthetic`                             |
