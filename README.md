# SonArt
Веб-дашборд для анализа Big Data в учреждениях культуры.  Система объединяет данные о посещаемости, обратной связи и вовлечённости аудитории, визуализирует ключевые показатели, сегментирует посетителей с помощью кластеризации и формирует рекомендации по планированию культурных мероприятий.
