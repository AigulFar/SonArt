# AI_section

## Что здесь находится

- `ai_predict.py` — HDBSCAN-кластеризация аудитории.
- `ai_predict2.py` — CatBoost-прогноз заполняемости мероприятия.
- `ai_pipeline.py` — единая точка входа для сайта/API: принимает параметры мероприятия и возвращает лучшие организации/площадки с числовым прогнозом.
- `ai_rec.py` — существующий модуль сокомандника для GigaChat/LLM. Его не удаляем.
- `audience_rules.txt` — правила для LLM. Его не удаляем.
- `llm_output_schema.json` — формат ответа LLM. Его не удаляем.
- `.env.example` — пример переменных окружения. Секреты в GitHub не коммитим.
- `requirements.txt` — зависимости.

## Логика

```text
Пользователь
    ↓
описание мероприятия
    ↓
ai_pipeline.py
    ├── CatBoost → прогноз посещаемости
    └── подбор организаций/площадок
    ↓
результаты ML
    ↓
ai_rec.py → LLM
    ↓
понятная рекомендация
```

LLM не должна сама придумывать числовые прогнозы.

## Запуск из корня SonArt

```bash
python AI_section/ai_predict.py
python AI_section/ai_predict2.py
python AI_section/ai_pipeline.py
```

Для LLM-модуля нужен `.env` с ключом GigaChat. Файл `.env` не коммитить.

## Важное ограничение

ML-часть обучается на синтетических исторических мероприятиях, поэтому прогноз — демонстрационный результат прототипа, а не реальный прогноз посещаемости учреждений.
